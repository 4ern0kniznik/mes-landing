# Лендинг и прототип MES с APS-ядром

Статический сайт: лендинг продукта и кликабельное демо двух экранов системы —
пульта мастера и цехового терминала. Публикуется через GitHub Pages,
никакого бэкенда для работы не требуется.

## Состав

```
index.html          лендинг: задача, возможности, тарифы, калькулятор, условия пилота
demo/index.html     оболочка демо: вкладки «Пульт мастера» / «Терминал оператора»
demo/master.html    экран мастера — копия app/static/master.html с демо-стором
demo/terminal.html  экран оператора — копия app/static/terminal.html с демо-стором
demo/store.js       демо-стор: отвечает на те же вызовы, что REST API, из data.js
demo/data.js        выгрузка реального прогона решателя (данные демо)
tools/              скрипты, которыми data.js и экраны демо пересобираются
.nojekyll           отключает обработку Jekyll на GitHub Pages
```

Экраны демо не переписаны вручную: это файлы из `app/static/` с одной заменой —
сетевой `api()` подменён на `window.MES_DEMO_API` из `store.js`. Поэтому демо
не расходится с системой: поменялся экран в приложении — пересоберите демо.

## Данные демо

`demo/data.js` — не выдумка, а дамп настоящего прогона: справочники из `app/seed.py`,
50 заказов, 213 операций, решение CP-SAT, неделя закрытых смен с фактом,
простои и рассчитанный OEE. Состояние живёт в памяти вкладки: старт операции
в терминале виден на диаграмме мастера, кнопка «Сбросить демо» возвращает исходное.

## Пересборка

Из корня проекта MES, в окружении с зависимостями проекта:

```
python tools/make_demo_data.py
python tools/make_demo_screens.py
```

Первый скрипт поднимает временную БД, сеет справочники, добавляет заказы,
запускает решатель, проставляет факт за прошедшую неделю и пишет `demo/data.js`.
Второй копирует `app/static/master.html` и `terminal.html` в `demo/` с подменой `api()`.

## Локальный просмотр

```
python -m http.server 8899
```

Затем открыть http://127.0.0.1:8899/ — лендинг, http://127.0.0.1:8899/demo/ — прототип.
Открывать файлы напрямую через `file://` не нужно: браузер заблокирует загрузку
`data.js` внутри фреймов.
